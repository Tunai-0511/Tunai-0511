My work focuses on turning raw signals into usable decision-support products: agent pipelines, real-time dashboards, multimodal workflows, and backend services that connect models, APIs, local storage, and user-facing interfaces.

My current engineering direction is centered on **Python-based AI systems**, **full-stack data products**, and **agentic applications** that combine reliable software architecture with practical machine intelligence. ## Featured Projects

<details>
<summary><b>AgentAQI - Personal AI Agent Air Quality Monitoring Platform</b></summary>

<br/>

A dark, SaaS-style air quality intelligence platform for Taiwan that connects real environmental data, multi-agent analysis, personalized health context, and chatbot-ready exports. The system turns public AQI data into individual decision support for users who need practical guidance, not just numbers.

| Category | Details |
|---|---|
| Stack | Python, Streamlit, Pandas, NumPy, Plotly, SQLite, Requests, LLM APIs |
| Scale | Taiwan-wide monitoring across 20 cities and counties |
| Performance | Local cache, API fallback paths, time-series snapshots, fast Streamlit interaction |
| Security | Local-first user profile handling, API key input through app controls, no forced external account dependency |
| Impact | Converts national air quality data into personalized health and outdoor activity decisions |
| Repository | [Tunai-0511/aqi-tw-personal](https://github.com/Tunai-0511/aqi-tw-personal) |

**Engineering Highlights**

- Built a three-agent workflow: collector, analyst, and advisor
- Integrated MOENV EPA data, Open-Meteo, CAMS, LASS, and citizen sensor sources
- Designed personalized health recommendations using user profile data and AQI thresholds
- Created chatbot handoff via exported JSON contract for platform-neutral agent integration
- Implemented dashboard sections for real-time AQI, pollutant breakdowns, trends, health logs, and city-level detail

</details>

<details>
<summary><b>Vision Nav Agent - Vision-Aided Navigation Assistant</b></summary>

<br/>

An AI-assisted navigation system designed for visually impaired users and older adults. The project combines computer vision, voice interaction, FastAPI services, GPS context, Google Calendar workflows, Telegram integration, and OpenClaw-style decision logic.

| Category | Details |
|---|---|
| Stack | Python, OpenCV, YOLOv8, FastAPI, Uvicorn, SpeechRecognition, pyttsx3, SQLite, Google APIs |
| Scale | Camera-based local navigation assistant with web/mobile service interface |
| Performance | Frame analysis pipeline, threaded service operations, local voice feedback loop |
| Security | Local runtime focus, environment-based secrets, controlled API endpoints |
| Impact | Accessibility-focused AI system for safer movement, object awareness, and daily assistance |
| Repository | [Tunai-0511/vision_nav_agent](https://github.com/Tunai-0511/vision_nav_agent) |

**Engineering Highlights**

- Built camera capture and obstacle detection flow with OpenCV
- Added voice output and command handling for hands-free interaction
- Designed FastAPI endpoints for mobile image upload, GPS ingestion, schedule creation, and photo analysis
- Integrated YOLOv8, Google Calendar, Telegram messaging, and local storage modules
- Focused the system around practical assistive navigation and daily-life support

</details>
